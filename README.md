# 同城搭子活动组局H5系统源码-伴伴搭子系统源码/H5同城组局找搭子系统源码
源码获取：ym7k.com/18853/

伴伴搭子是一套主打**同城线下组局、兴趣搭子匹配**的 H5 社交系统，支持 H5 + 公众号，可扩展小程序，适合做饭搭子、运动、徒步、剧本杀、探店、游戏、观影、骑行等同城兴趣组局流量项目，源码可独立部署、支持二次开发，自带完整后台管理、用户社交、活动交易、风控审核全套模块。

## ✅ 技术架构

- 后端：PHP + MySQL（也有 Java 版本可选）
- 前端：Vue + UniApp，H5 移动端适配，一套前端兼容手机浏览器、微信内置浏览器
- 部署：独立服务器部署，源码交付，非 SaaS；支持域名绑定、SSL 证书、微信授权登录、微信支付对接

## ✅ 用户 H5 端核心功能

1. **微信快捷登录 + 实名认证**：微信一键授权、手机号绑定，可选实人认证，降低线下社交风险；支持头像、昵称、性别、年龄、兴趣标签、常驻区域、个人简介设置
2. **同城定位 & 搭子智能匹配**：LBS 定位，按距离、兴趣标签、活动类型智能推荐搭子；可筛选距离、性别、年龄、活动品类，精准找搭子
3. **活动组局发布大厅**：用户自主发起组局，填写活动标题、封面、时间、地点、人数上限、费用模式（AA / 自费 / 收费）、活动详情；活动分类：美食、运动、桌游、露营、探店、看展、自驾游、学习搭子等
4. **报名、审核、成团机制**：用户一键报名，发起人审核入队；满员自动成团、超时自动取消；活动状态：招募中、已成团、已结束、已取消
5. **即时 IM 私信 + 活动群聊**：一对一私聊、活动临时群聊，支持图文、位置发送；消息推送提醒（报名通知、私信、活动提醒）
6. **订单支付 & 分账**：支持活动报名费、AA 收款；订单明细、退款申请、支付记录；可配置平台抽成比例
7. **个人中心**：我的发起、我的报名、我的搭子、收藏活动、消息列表、评价中心、钱包余额、提现
8. **评价 & 举报风控**：活动结束双向评价，生成信用分；违规用户举报、拉黑功能，违规内容一键上报

## ✅ 管理后台功能

1. 用户管理：用户列表、账号封禁、实名审核、信用分管理
2. 活动管理：所有活动审核、下架违规活动、编辑、删除；活动分类自定义
3. 订单资金：订单流水、提现审核、平台收益统计、对账导出
4. 内容风控：敏感词库配置、聊天内容监控、举报工单处理
5. 广告运营：首页轮播图、弹窗广告、公告设置、热门活动置顶
6. 会员 & 分销合伙人（增值模块）：开通 VIP 会员、合伙人邀请分销，邀请新用户拿提成，适合引流裂变
7. 数据看板：同城在线人数、活动发布量、报名成交、新增用户、地域流量统计

## ✅ 可拓展增值模块

- 商家入驻：线下餐饮、桌游馆、轰趴馆入驻，发布套餐活动
- 付费进群：付费解锁搭子社群，适合轻变现
- 打卡动态广场：用户发布同城动态、图文，类似朋友圈引流
- 达人认证：优质组织者、带队达人标识，提升信任感

## ✅ 项目变现模式

- 活动报名抽佣（主流）
- VIP 会员，解锁无限匹配、优先置顶、免审核
- 合伙人分销拉新奖励
- 商家入驻费、广告位售卖
- 付费社群门槛费
